# GDG KITS- Developer student Community Website
 
This project is a **Student Community Website** for the google developrer students Developer groups at (GDG-KITS) at Kavikulguru Institute of Technology and science, In this website we show Our Teams of all gdg Groups, Missionsm, Oue events, Showcase of team, Workshop and provide students to connect with us. 

## 📂 project structure 
- index.html-Main body content of the website
- style.css- make coloetful and attractive blocks(layout, theme, responsicveness )
- script.js- Javascript file with button interactive 

## 🎨 Features
- Responsive **navigation bar** with light/dark theme toggle.
- Hero section with **Explore Community** and **Our Events** buttons.
- About section with **community stats**.
- Features section highlighting **workshops, hackathons, tech talks, open source**.
- Call-to-action (CTA) section to encourage joining.
- Contact form with **form validation and success alert**.
- Footer with **social media links** (GitHub, LinkedIn, Instagram, Twitter).
